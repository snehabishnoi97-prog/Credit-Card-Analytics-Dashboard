# Credit-Card-Analytics-Dashboard
##power bi dashboard
##The main objective of this project is to analyze credit card transction and customer data using power bi by importing data from an excel workbook and creating interactive dashboard for better business insights.                                        ## The project helps in :                                                                                                         1. Understanding customer spending behavior                                                                                    2. Traking transaction trend and payment methods                                                                               3. Monitoring customer demographics                                                                                            4. Conerting raw excel data into meaningful visual reports for decision making
##Steps taken :                                                                                                                  1. Collected credit card transaction and customer data from an Excel workbook                                                2. Importing Data into Power BI                                                                                                3. Data Cleaning and Transformation                                                                                            4. Data Modeling                                                                                                                   - Established relationships between customer and transaction tables                                                            - Created calculated measures using DAX functions 
##Dashboard 1: Credit Card Analytics Dashboard                                                                                    key insight displayed :                                                                                                           - Total revenue                                                                                                                - Revenue by use chip                                                                                                          - Revenue by expenditure                                                                                                       - Revenue by aqu card    
##Dashboard 2: Credit Card Customer Dashboard                                                                                       key insight displayed :                                                                                                         - Revenue by gender                                                                                                          - Customer income analysis                                                                                                   - Customer state-wise analysis                                                                                               - Revenue by age group                                                                                                       - Revenue by marital status
